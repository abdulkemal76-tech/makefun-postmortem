Entry for the make.fun bounty [The Postmortem That Made Us Laugh](https://make.fun/bounty/u-swift-raven-16-the-postmortem-that-made-us-laugh-268457a3).

`main.py` (Python 3, standard library only) writes one short account, one or two sentences and no more than 400 characters, of the silliest time an AI coding agent misunderstood what it was asked, to `/output/entry.txt`.

Run it with:

```sh
python3 -P -s main.py
```
